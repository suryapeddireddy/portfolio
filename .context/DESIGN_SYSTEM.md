# UI & Design System Context

## Primary Design Inspiration
- Reference Aesthetic: https://www.radnaabazar.com/en (Aceternity / Bento Grid Dark Mode)
- Theme: "Futuristic Command Deck"
- Core Philosophy: Dark mode first, high contrast, crisp 1px borders, subtle cyan/mint glows, zero-lag performance.

## Design Tokens (`src/app/globals.css`)
- Base Background: Obsidian `#030712` (`.bg-command-grid`)
- Surface Cards: Cyber-Slate `#0B0F17` (`.deck-card`)
- Border Subtle: `#1E293B`
- Accent Cyan: `#06B6D4` (handles, values, interactive links)
- Accent Mint: `#10B981` (live status indicators, success states)
- Accent Amber: `#F59E0B` (pedigree, awards, highlights)

## Typography Rules
- Headers & Body: Clean Sans-Serif (`Inter` / system-ui)
- Badges, Metrics, Status, Code Tags: `JetBrains Mono` / `font-mono`
